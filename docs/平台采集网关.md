# 平台采集网关协议

中台不会直接模拟登录各个平台，而是调用部署方配置的采集网关。采集网关应优先使用平台官方 API，并遵守平台授权及数据使用规则。

中台向 `PLATFORM_SYNC_ENDPOINT` 发起 `POST application/json` 请求：

```json
{
  "platform": "douyin",
  "handle": "account-handle",
  "credential": { "username": "...", "password": "..." }
}
```

若设置 `PLATFORM_SYNC_API_KEY`，请求包含 `Authorization: Bearer <key>`。网关应返回：

```json
{
  "followers": 12000,
  "works": [
    {
      "id": "platform-work-id",
      "title": "作品标题",
      "url": "https://example.com/work",
      "format": "短视频",
      "publishedAt": "2026-08-26T02:00:00+08:00",
      "views": 1000,
      "impressions": 1200,
      "likes": 80,
      "comments": 12,
      "shares": 6,
      "saves": 15
    }
  ]
}
```

作品指标为平台当前累计值。中台在每次同步时自动换算为当天增量；同一天重复同步会覆盖当天记录，不会重复累计。单次最多处理 500 条作品，请求超时为 45 秒。
